# Hi, I'm Bala 👋

**Senior AI Engineer · Agentic AI & RAG systems · Bangalore, India**

I build LLM applications that hold up outside a demo: retrieval pipelines, multi-agent workflows, and the guardrails and evals that make them trustworthy. 8 years in the data domain, 4+ of them building GenAI systems for real clients.

## What I work on

- **Agentic systems:** multi-agent orchestration, ReAct agents, human-in-the-loop approval flows
- **RAG:** from basic pipelines to agentic and production-grade retrieval
- **Safety & reliability:** LLM gateways, guardrails, evals, observability
- **Forward-deployed work:** turning an ambiguous problem into a working system with the people who will use it
